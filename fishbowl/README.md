# Fish Bowl — Sartori AI

A 58-slide talk given at the University of Illinois: the path from a 54-hour
Startup Weekend in 2012 to Sartori AI's B2B returns-intelligence wedge, with
seven entrepreneurship concepts taught at the moment the story earns them.

**Live:** https://bob-michael-prodmgmt.github.io/r_michael_merritt_website/fishbowl/

## Presenting

| Key | Action |
| --- | --- |
| `←` `→` / click screen edges | Previous / next slide |
| `O` | Overview of all 58 slides |
| `S` | Toggle presenting view and scrollable stack |
| `F` | Fullscreen |

Open the page in its own browser tab before presenting — fullscreen is blocked
inside an embedded frame.

## Structure

Eleven acts, four photographic dividers, 7 concept slides, 15 hand-drawn SVG
infographics, 3 live embeds (consumer demo, SRII assessment, Field Qualifier).
Each live embed has a launch button as a fallback if the venue network blocks
framing.

Self-contained: one `index.html` plus `assets/`. No build step.
